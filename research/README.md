# Research Documentation

This folder contains the machine-readable evidence ledgers and prior-art benchmarks used to ground our operational modeling:

- `literature_evidence.json`: Source-scoped benchmark parameters from public e-commerce logistics studies, SEBI disclosures, and Indian delivery network publications.
- `prior_art_audit.json`: Audited technical parameters across existing last-mile logistics platforms, geocoding standards (DIGIPIN), and payment retry systems.
